AIWS provides built-in commands to reclaim disk space safely (`aiws cache`) and back up or restore DSH state (`aiws state`).

---

## Cache Management

### Storage Inspection

```bash
aiws cache
```

Outputs three storage reports:
- **`=== Docker ===`** — `docker system df` (images, containers, local volumes, and build cache).
- **`=== AI runtime ===`** — `du -sh ~/aiws/runtime`.
- **`=== Project node_modules ===`** — Disk usage of every `node_modules` directory under `~/projects/*`.

### Safe Cleanup

```bash
aiws cache clear
```

Cleans reclaimable **Docker builder cache** (`docker builder prune -af`) and **in-container npm cache** (`npm cache clean --force`).

### Protected Paths

`aiws cache clear` is designed so it **never removes**:
- DSH state (`runtime/dsh`)
- DSH installation (`runtime/npm-global`)
- `.env` configuration
- Git repositories (`~/projects/*`)
- Docker images (`ghcr.io/mosabbir-maruf/aiws`)
- Docker containers (`aiws`)
- Docker volumes

### Dependency Purge

To remove `node_modules` directories across all repositories in `~/projects/*`:

```bash
# Interactive confirmation
aiws cache clear --deps

# Non-interactive
aiws cache clear --deps --yes
```

Recommended dependency reset sequence:

```bash
aiws app stop
aiws cache clear --deps
aiws run
```

When `aiws run` executes next, dependencies are cleanly reinstalled from the project lockfile (`npm ci`, `pnpm install --frozen-lockfile`, `yarn install --immutable`, or `bun install --frozen-lockfile`).

## State Backup

Project source code lives in GitHub, while DSH workflow state (`runtime/dsh`) and `.env` are backed up via encrypted off-host `.tar.gz` archives.

### Export Snapshot

```bash
aiws state export
```

Creates `~/aiws-state-backups/aiws-state-<timestamp>.tar.gz` (permissions `0600`).

### Archive Manifest

| Included in Snapshot | Excluded from Snapshot |
|---|---|
| `manifest` (version, timestamp, `DSH_VERSION`) | `runtime/npm-global` |
| `.env` | `runtime/app` & `runtime/harness` |
| `runtime/dsh/` (`settings.yaml`, `.credentials.yaml`, `storages/`) | `runtime/github-broker` & `github.sock` |
| — | `secrets/github-app.pem` & `~/projects/*` |

### Import Snapshot

```bash
aiws stop
aiws state import ~/aiws-state-backups/aiws-state-20260925-020000.tar.gz
aiws start
aiws dsh version
```

During import, `aiws state import` validates archive member names (`manifest`, `.env`, `dsh/*`), blocks relative/absolute path traversal (`..`), rejects hardlinks, verifies symlinks point strictly within `/home/sandbox/.npm-global/*`, backs up the existing state before replacement, and restores `0600`/`0700` file permissions.
