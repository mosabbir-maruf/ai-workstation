## Projects

```bash
aiws add <github-url>
aiws remove <project>
aiws list
aiws use <project>
```

- **`aiws add <github-url>`** — Validates and clones a GitHub HTTPS repository (`https://github.com/<owner>/<repo>`) into `~/projects/<name>`.
- **`aiws remove <project>`** — Stops the workstation if removing the active project and deletes `~/projects/<name>`.
- **`aiws list`** — Lists all Git repositories in `~/projects/` and marks the active project with `*`.
- **`aiws use <project>`** — Updates `ACTIVE_PROJECT` and `ACTIVE_PROJECT_PATH` in `.env`, recreates the `/workspace` container mount if `aiws` is running, and restarts the Harness.

## Git

```bash
aiws pull
aiws push "commit message"
```

- **`aiws pull`** — Executes `git pull --ff-only` inside the active project directory (`ACTIVE_PROJECT_PATH`).
- **`aiws push "commit message"`** — Stages all modified files (`git add -A`), scans staged filenames for sensitive file patterns (`.env`, `.env.*` except `.env.example`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, `credentials.json`, `service-account*.json`), aborts and resets staging if any match is found, and otherwise commits and pushes via the GitHub App credential broker.

## Runtime Commands

```bash
aiws start
aiws stop
aiws restart
aiws status
aiws logs
aiws shell
aiws run
aiws preview
```

- **`aiws start`** — Initializes `runtime/dsh`, `runtime/npm-global`, and `runtime/harness` (`0700`, `1001:1001`), starts `aiws` via Docker Compose, and launches DSH + Bridge (`aiws harness start`).
- **`aiws stop`** — Stops the active project app, stops the Harness, tears down the `aiws` container, and cleans up `runtime/app/pid`.
- **`aiws restart`** — Restarts the `aiws` container and starts the Harness.
- **`aiws status`** — Displays the active project, container status (`running`/`stopped`), Harness (`DSH` + `Bridge`) status, and App status/PID.
- **`aiws logs`** — Streams `docker compose logs -f --tail=100`.
- **`aiws shell`** — Opens an interactive `bash` session inside `aiws` as user `sandbox` (`UID 1001`) at `/workspace`.
- **`aiws run`** — Detects the project package manager (`npm`, `pnpm`, `yarn`, `bun`), installs missing dependencies from lockfiles, auto-injects `0.0.0.0` host flags (`--host 0.0.0.0` or `-H 0.0.0.0`), and runs the dev server in the background via `/usr/local/bin/app-runner.sh`.
- **`aiws preview`** — Inspects the container IP, detects listening app ports via `scripts/lib/ports.sh`, prints the ready-to-run `ssh -N -L ...` command, and prints Cloudflare Tunnel Anywhere URLs (`App`, `DSH`, and `DSH open:` with token).

## App Supervisor

```bash
aiws app stop
aiws app restart
aiws app status
aiws app logs
```

- **`aiws app stop`** — Terminates the active project process group (`PGID`) and PID inside the container (`SIGTERM` followed by `SIGKILL` cleanup).
- **`aiws app restart`** — Runs `aiws app stop` followed by `aiws run`.
- **`aiws app status`** — Prints the active project name, running state, and container PID.
- **`aiws app logs`** — Streams `/run/aiws/app/app.log` (`tail -n 100 -f`).

## Harness & DSH

```bash
aiws harness start
aiws harness stop
aiws harness restart
aiws harness status

aiws dsh version
aiws dsh update
aiws dsh update <version>
```

- **`aiws harness {start|stop|restart|status}`** — Controls the container-internal DSH web process (`127.0.0.1:4090`) and TCP bridge (`0.0.0.0:4091`) via `/usr/local/bin/harness.sh`.
- **`aiws dsh version`** — Outputs the installed `@deepseek-ai/dsh` version in `/home/sandbox/.npm-global`.
- **`aiws dsh update [version]`** — Installs `@deepseek-ai/dsh@latest` (or a pinned release tag) into persistent `/home/sandbox/.npm-global` without rebuilding the Docker image.

## Maintenance

```bash
aiws cache
aiws cache clear
aiws cache clear --deps
aiws cache clear --deps --yes
aiws update
aiws upgrade
aiws doctor
```

- **`aiws cache`** — Read-only disk report (`docker system df`, `du -sh runtime`, and `~/projects/*/node_modules`).
- **`aiws cache clear [--deps] [--yes]`** — Prunes Docker builder cache (`docker builder prune -af`) and npm cache (`npm cache clean --force`), plus removes `~/projects/*/node_modules` when `--deps` is passed.
- **`aiws update`** — Fast-forward updates `~/aiws` (`git pull --ff-only`) and pulls latest compose images.
- **`aiws upgrade`** — Runs `aiws update`, recreates the container (`compose up -d`), and restarts the Harness.
- **`aiws doctor`** — Runs the full 20-point verification suite across Docker, `.env`, active project mount, container user/cgroups/capabilities (`sandbox`, `512 MB`, `1.5 CPU`, `256 PIDs`, `cap_drop: ALL`, `no-new-privileges`), DSH/Harness, and `github.sock`.

## Broker, Tunnel & State

```bash
# GitHub App Broker
aiws github setup
aiws github status
aiws github test

# Cloudflare Tunnel (Anywhere Access)
aiws tunnel setup
aiws tunnel sync [port]
aiws tunnel status
aiws tunnel start
aiws tunnel stop
aiws tunnel logs

# State Backup & Restore
aiws state export
aiws state import <archive>

# Host Control Daemon (Web Dashboard API)
aiws daemon start
aiws daemon stop
aiws daemon restart
aiws daemon status
aiws daemon logs
```

- **`aiws daemon {start|stop|restart|status|logs}`** — Manages the native async Python host bridge service on `127.0.0.1:8000`, providing the HTTP endpoints and real-time SSE streams consumed by the AIWS Web Dashboard.
